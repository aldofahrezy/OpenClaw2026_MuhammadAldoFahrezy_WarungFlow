# USER

**Target User Context**

**Hackathon Context**: OpenClaw Agenthon Indonesia 2026. This project is built to demonstrate clear agentic capabilities: tool calling ("tangan"), memory, state, reasoning, and autonomous loop control.

**End-User Context**: Primary users are Indonesian UMKM owners, warung owners, food sellers, and online merchants.
**Demo Merchant**: Warung Bu Sari. She receives messy food orders via WhatsApp, accepts QRIS, bank transfer, and cash, and struggles to reconcile daily transactions, leaving unpaid orders uncollected. WarungFlow helps her cleanly reconcile the day and get paid.
